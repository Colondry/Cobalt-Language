# Cobalt Programming Language

**Cobalt** is a modern, compiled programming language that transpiles to **C++**, combining simplicity with performance. It is designed to be easy to learn, flexible to use, and capable of producing fast native applications.

> ⚠️ **Current Status:** Alpha (v0.3)
> Cobalt is under active development. Features, syntax, and APIs may change between releases.

## ✨ Features

* 🚀 Compiles to modern C++
* ⚡ Fast native performance
* 📚 Simple syntax
* 🌍 Cross-platform (Windows & Linux)

## Example

```cobalt
fn main(): int {
    println("Hello, World!");
    ret 0;
}
```

## Why Cobalt?

Cobalt was created as a personal project to explore compiler development and programming language design. The goal is to build a language that is approachable for beginners while remaining powerful enough for larger applications.

Although this is my **first programming language**, every release is an opportunity to learn, improve, and make Cobalt better.

## Project Status

Cobalt is currently in the **Alpha** stage.

Expect:

* New features
* Breaking syntax changes
* Compiler improvements
* Bug fixes
* Errors

Feedback, suggestions, and contributions are always welcome!
